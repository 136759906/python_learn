# 第 2 周：PostgreSQL、FastAPI CRUD 与 Vue 表单

目标：完成数据库持久化的待办清单。参考工程位于 `project/`，先让它跑通，再逐个改动代码。PostgreSQL 是唯一的正式数据库；测试使用临时 SQLite 以保持运行速度，但验收要在 PostgreSQL 上手工走一遍。

## 第 6 天：启动 PostgreSQL

在 `project/` 复制 `.env.example` 为 `.env`，把 `POSTGRES_PASSWORD` 改成自己的值；`.env` 不提交 Git。如果已有本机 PostgreSQL，可自行创建 `todo` 用户和 `todo` 数据库；使用 Docker 时运行：

```powershell
docker compose up -d db
docker compose ps
```

用 `docker compose exec db psql -U todo -d todo` 进入 `psql`，执行 `SELECT current_database();`。如果使用本机 PostgreSQL，先用管理员账户执行 `CREATE ROLE todo LOGIN PASSWORD '你的练习密码';` 和 `CREATE DATABASE todo OWNER todo;`，再用 `psql -h localhost -U todo -d todo` 连接。练习：说明数据库名、用户、密码、主机、端口各在哪里设置。验收：能连上 `todo` 库；知道容器内的主机名是 `db`，本机 Python 通常使用 `localhost`。

## 第 7 天：表、主键与 SQL

阅读 `project/backend/app/models.py`：`id` 是主键，`title` 非空，`done` 有默认值。先在 `psql` 手动建表，对照 ORM 字段：

```sql
CREATE TABLE tasks (
    id INTEGER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    title VARCHAR(100) NOT NULL,
    done BOOLEAN NOT NULL DEFAULT FALSE
);
INSERT INTO tasks (title) VALUES ('学习 PostgreSQL');
SELECT id, title, done FROM tasks;
```

执行 `\d tasks` 看列类型，再用 `DELETE FROM tasks WHERE title = '学习 PostgreSQL';` 清理练习数据。验收：能解释主键为何唯一、布尔列为何不能随意写空。若表已由后端创建，不要重复建表，直接做插入和查询。

> 示例用 SQLAlchemy 的 `create_all` 建表，只适合教学初期。已有数据的结构变更将在进阶练习中学习迁移工具，不要靠删除数据卷重建生产库。

## 第 8 天：SQLAlchemy Session 与 API

在 `project/backend/` 创建虚拟环境并安装 `requirements.txt`，设置 `DATABASE_URL=postgresql+psycopg://todo:<密码>@localhost:5432/todo`，运行 `python -m uvicorn app.main:app --reload`。阅读 `database.py` 的 `SessionLocal`、`get_db` 和 `main.py` 的 `commit/refresh`。在 `/docs` 中按 POST → GET → PATCH → DELETE 执行一遍。验收：重启后端后已保存任务仍存在；不存在的 ID 返回 404。

## 第 9 天：Pydantic 与 Vue 表单

阅读 `schemas.py`：输入模型约束标题长度，输出模型只暴露需要的字段。阅读 `frontend/src/api.js` 和 `App.vue` 的 `v-model`、`@submit.prevent`、加载中和失败提示。练习：提交空标题、只有空格的标题、正常标题。验收：前端阻止空提交；即使绕过前端，后端也返回 422；成功后刷新页面仍能看到任务。

## 第 10 天：联调与数据库核对

用页面添加、完成、删除任务，同时在 `psql` 中 `SELECT id, title, done FROM tasks ORDER BY id;` 核对。关闭后端再操作，观察错误提示。验收：浏览器 Network 中的请求方法和数据库变化一致；前端不保存“假成功”状态。

参考：[FastAPI 请求体](https://fastapi.tiangolo.com/tutorial/body/)、[SQLAlchemy ORM 快速开始](https://docs.sqlalchemy.org/en/20/orm/quickstart.html)、[PostgreSQL 教程](https://www.postgresql.org/docs/current/tutorial.html)、[Vue 表单绑定](https://vuejs.org/guide/essentials/forms.html)。
