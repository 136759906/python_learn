# 阶段三：AI 应用开发（4-6 周，生产实战版）

目标：不是"能调通 API"，而是做出**可评估、可观测、成本可控、有安全边界**的 AI 应用，
并且回答得了 `interview_questions.md` 里的问题。

## 课程安排

### 第一周：LLM API 工程化基础

| 天 | 主题 | 生产要点 |
|----|------|----------|
| 1 | OpenAI/Claude SDK 接入、消息结构 | API Key 用环境变量；超时、连接池配置 |
| 2 | Prompt Engineering：结构化提示、few-shot | 提示词放代码/配置文件版本化管理，不写死在业务代码里 |
| 3 | 流式输出：SSE、chunk 解析 | 断流处理、前端渲染、工具调用与流式共存 |
| 4 | 结构化输出：JSON mode / Pydantic 校验 | **模型输出的 JSON 必须再用 Pydantic 校验**，校验失败自动重试 |
| 5 | 错误处理：限流、超时、重试、降级 | 指数退避；429/503 重试，内容违规不重试；主模型挂了切备用模型 |

**周末**：过面试题 1-5。

| 天 | 主题 | 生产要点 |

## 实践项目（企业知识库问答，生产标准）

1. 文档解析：支持 PDF/Markdown，解析失败有日志和兜底
2. 分块与索引：按标题结构分块，入库幂等可重跑
3. 混合检索：向量 + BM25 + 重排，检索结果带来源引用
4. 生成约束：只根据资料回答，没资料就明确说不知道
5. 评估集：至少 30 个问答对，能跑出 recall@5 和忠实度指标
6. 可观测：每次问答记录 token、耗时、命中文档，成本可统计
7. 安全：多租户数据隔离；对知识库内容做注入隔离
