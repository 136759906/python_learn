# Python 学习路径（生产实战版）

以"能写出生产可用的代码"为标准，不以"看懂示例"为目标。

## 核心原则

1. **生产优先**：每个知识点都回答三个问题——生产中怎么用？会踩什么坑？面试官会怎么问？
2. **面试驱动**：Web 和 AI 阶段每完成一周学习，就过一遍对应的面试题（带参考答案）。
3. **评估思维**：AI 应用开发的重点是可评估、可观测、可控制成本，而不是只调一次 API。
4. **工程习惯**：从一开始就养成类型注解、异常处理、日志、测试的习惯。

## 生产习惯清单（贯穿所有阶段）

写任何代码前先默念一遍：

1. 函数有类型注解吗？
2. 异常被正确捕获并记录日志了吗？
3. 需要的配置是从环境变量/配置文件读的，还是硬编码的？
4. 关键逻辑有没有对应的测试？
5. 坏输入会不会把程序搞崩？
6. 如果这是线上服务，出问题时我能从日志定位到原因吗？
