# 项目 2：批量文件整理工具

## 目标

实现 `organizer.py`，把指定目录下的文件按类型自动归档到子文件夹。

## 功能要求

1. **基本整理**：把 `.jpg/.png/.gif` 移入 `images/`，`.mp4/.mkv` 移入 `videos/`，`.pdf/.docx` 移入 `docs/`，其他文件移入 `others/`
2. **预览模式**：`python organizer.py <目录> --dry-run`，只显示将要移动的文件，不实际移动
3. **冲突处理**：目标文件夹存在同名文件时，自动加后缀（如 `a(1).txt`）
4. **子目录跳过**：只整理第一层文件，不递归处理子目录

## 技术要点

- `pathlib.Path` 处理路径（比 os.path 更现代化）
- `shutil.move()` 移动文件
- `Counter` 统计各类型文件数量
- 函数拆分：每个功能一个函数，主函数组装流程
