## 生产习惯（本阶段养成）

1. **print 换成 logging**：模块级 `logger = logging.getLogger(__name__)`
2. **类型注解必写**：`def add(a: int, b: int) -> int:`
3. **except 必须记录日志并重新抛出或返回明确结果**，不许裸 `except: pass`
4. **配置不硬编码**：路径、金额上限等用环境变量或 argparse 参数
5. **写测试**：每个项目至少覆盖核心函数的正常路径和异常路径

## 本阶段高频面试考点

学习时留意这些问题的答案就藏在课程里，项目做完后要能脱口而出：

1. 可变类型作为函数默认参数的坑（`def f(items=[])`）
2. `is` 和 `==` 的区别；小整数缓存现象
3. 深拷贝和浅拷贝的区别及应用场景
4. 装饰器的执行时机；带参数的装饰器怎么写
5. 生成器和列表的区别；什么场景用生成器（大文件处理）
6. GIL 是什么；CPU 密集和 IO 密集任务分别怎么优化
7. `dict` 的底层实现；为什么字典查找是 O(1)
8. 闭包和作用域（LEGB）；`global` / `nonlocal`
9. `*args` 和 `**kwargs` 的解包与打包
10. 上下文管理器（with）的实现原理（`__enter__` / `__exit__`）
